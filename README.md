# ET - English Translator

> A lightweight English reading assistant for your browser.
> **Select · Translate · Listen · Learn**

ET is a minimal Chrome extension (Manifest V3): select English text on any webpage, click the ET icon, and get an instant in-page translation card — with British 🇬🇧 / American 🇺🇸 pronunciation playback and single-word dictionary lookups.

## Features

- **Select to translate** — select English text on a webpage to reveal a small ET action icon; click it to open an in-page translation card.
- **Multi-language output** — translate into Chinese, Japanese, Korean, French, German, or Spanish.
- **Dictionary mode** — for a single English word, show IPA and definitions when the dictionary service has an entry.
- **British / American pronunciation** — read the original text using an available `en-GB` or `en-US` system/browser speech voice.
- **Local word list** — save selected words locally in Chrome storage. Nothing is sent to any custom server.
- **Repeat lookups are free** — the last 400 translations are cached for 30 days, so re-selecting the same text doesn't hit the network again. If a request fails, the card says why (rate limited, timed out, unexpected response) and offers a retry.

## Install (from source)

1. Clone or download this repository.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the `ET-Chrome-Extension` folder.
5. Open a webpage, select English text, and click the ET icon.

## Privacy

- ET does not have a backend and does not collect, store, or transmit data to any server of its own.
- Selected text is sent to two third-party services for processing:
  - **Google Translate** (public web endpoint) — for translation.
  - **Free Dictionary API** (dictionaryapi.dev) — for IPA and definitions.
- Saved words stay in your browser's local storage (`chrome.storage.local`) and never leave your machine.
- Permissions are kept minimal: `storage`, plus host access limited to the two service endpoints above.

## Important notes (MVP)

- Translation uses Google's public web translation endpoint. It is **not** an official Google Translate API and has no service-level guarantee. For a production release, connect a supported translation API or your own backend.
- Dictionary lookup uses the public Free Dictionary API. IPA/definitions are best-effort and may not exist for every word.
- British/American pronunciation uses voices installed by the operating system/browser. Voice quality and availability vary by device. The extension requests `en-GB` or `en-US`; if a matching voice is unavailable, the browser may fall back to its default voice.
- No audio files are bundled. Playback is generated by browser speech synthesis.
- This is a functional prototype, not yet Chrome Web Store-ready. See the Roadmap below for what's planned before publishing.

## Architecture

Single content script (`content.js`) injected at `document_idle`:

- Renders all UI inside a Shadow DOM host (`#et-extension-host`) so page styles can't leak in.
- `translate()` — Google public translate endpoint, with an 8-second timeout, a local result cache, and per-failure messages (rate limited / timed out / unexpected response) plus a retry button.
- `lookupWord()` — Free Dictionary API.
- Pronunciation — Web Speech Synthesis API.
- Storage — `chrome.storage.local`.

No build step, no dependencies, no framework.
